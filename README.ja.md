**ローカル優先で安全に管理できる Windows 向けファイル管理・ディスク整理ツールです。プレビュー優先、明示的な確認、操作の追跡に対応し、対応する操作ではロールバックでき、AI Agent も利用できます。**

スキャン分析、重複ファイル検出、ゴミファイル整理、ドライブ間の移動、スペースマップを備え、操作前に対象を確認できます。

ファイルを書き換える操作は、対象一覧を先に表示して確認を待ちます。手動の通常削除は既定で隔離領域に移し、元のパスとファイルシステムの状態が許す場合に復元できます。Agent による完全削除と隔離領域の消去は元に戻せず、明示して追加確認を求めます。
AI は指示を理解して計画を立てるだけで、実際にファイルを操作するのはローカルのコードです。
Agent のモデル要求と、ユーザーが明示的に実行する AI 説明を除き、スキャン・重複検出・整理・移行・バックアップはローカルで動作します。アカウントは不要です。

> 判断を代わりにするのではなく、「この操作でどのファイルが動くか」をそのまま見せます。

## はじめに

1. [Atlas-2.1.0-win64-portable.zip](https://github.com/whalevoyage/wenjianguanli/releases/latest) をダウンロードし、任意の場所に展開します（例：`D:\Atlas`）
2. `Atlas\Atlas.exe` をダブルクリックします
3. ブラウザが自動で開きます。コンソールウィンドウは表示されません。

Python や Node などの実行環境は不要です。`127.0.0.1` のみで待ち受け、データは `%LOCALAPPDATA%\Atlas` に保存されます。
アンインストールは、そのフォルダを削除するだけです。

**2 回目以降のダブルクリックでは新しいインスタンスは起動しません** — すでに動作中の画面をブラウザで開きます。
**ポート 8000 が使用中の場合は空いているポートに自動で切り替わり**、実際のアドレスはログに記録されます。

## 主な機能

| ページ | 内容 |
| --- | --- |
| ホーム | ディスク容量、解放可能な容量、タスク統計、最近のタスク |
| Atlas アシスタント | 自然言語での操作。ファイル作業を優先し、一般的な質問にも回答 |
| スペースマップ | ツリーマップでフォルダ容量を表示、階層を掘り下げ可能 |
| 整理プレビュー | 種類・時間・サイズ・プロジェクト別に整理結果をプレビュー（読み取り専用） |
| プロジェクトレーダー | プロジェクトフォルダを検出し、種類・容量・ファイル数・長期間未使用を表示 |
| スキャン分析 | 件数・容量・種類分布・大きいファイル・長期間未使用ファイル。スナップショットで前後比較 |
| 重複ファイル | バイト単位で重複を検出。「類似画像」にも対応（縮小・再圧縮・別名保存された同一画像、回転許容あり） |
| ゴミファイル | 一時ファイル・ログ・キャッシュ・空フォルダ・0 バイトファイルを 3 段階の危険度で検出 |
| 全文検索 | フォルダごとにローカル FTS5 インデックスを構築し、ファイル名と本文を検索 |
| ドライブ間移動 | コピーして 1 件ずつ検証し、検証後に元ファイルを処理。ロールバック可能 |
| プロジェクトバックアップ | ZIP スナップショットを作成（依存関係やビルドフォルダは除外）。復元確認も可能 |
| タスクセンター | 進捗・エラー・キャンセル・ロールバック状態を表示 |
| ゴミ箱 | 手動削除はまず隔離領域へ。パスとファイルシステムの状態が許せば復元を試せます |
| 操作ログ | 監査記録の表示とエクスポート |

## 安全性について

- 手動削除は一覧を確認してから既定で隔離領域へ移動します。元のパスとファイルシステムの状態が許せば復元できます。Agent の完全削除と隔離領域の消去は別途確認が必要な取り消せない操作です。
- 移動はコピーと検証が先で、検証に通ってから元ファイルを処理します。
- 長時間の処理はバックグラウンドタスクとして実行され、進捗確認・中断・ロールバックが可能です。
- プロジェクト自身のフォルダ、状態フォルダ、隔離領域は保護されます。
- システムフォルダは既定ではスキャンしません。標準モードでは書き込みを拒否し、完全アクセスでは明示操作で保護を緩和できます。Atlas のデータと隔離領域は引き続き保護されます。
- 既定で `node_modules`、`.git`、`__pycache__`、`.venv`、`dist`、`build` などを除外します。
- 移動・バックアップの前に、移動先の空き容量を確認します。
- `127.0.0.1` のみで待ち受け、LAN には公開しません。
