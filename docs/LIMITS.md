# 当前限制与已知遗留（2026-10-11）

> 对标 `qup1010/FilePilot` 的做法：把「现在做不到什么」和「已知哪里别扭」摊开写。
> 自己隔两周回来也知道边界在哪，不会把"限制"当成"bug"去查。

---

## 一、平台与形态

| 项目 | 现状 |
|---|---|
| 平台 | **只有 Windows**。接口层没有平台硬编码，但启动器（`packaging/launcher.py`）用的是 `ctypes` 弹窗 + WebView2，没在别的系统上试过 |
| 分发 | `Atlas.exe`（onedir）+ 便携 zip + 校验和。**没有自动更新** |
| 形态 | 三种：图形界面（默认）、`--mcp`（MCP server，只读）、`backend.cli`（命令行，只读） |
| 桌面窗口 | 优先 pywebview（WebView2）；装不上就退回浏览器，功能不减 |
| 中文 | 界面与文档全中文，没有做多语言 |
| 命令行 | 有 `python -m backend.cli`（scan / duplicates / similar / junk / tree / overview / reclaimed），**只读** |

## 二、扫描与统计

| 项目 | 现状 |
|---|---|
| 增量扫描 | **没有**。每次任务重新扫一遍，不做差异扫描 |
| 系统只读区 | `Windows` / `Program Files` / `ProgramData` / `$Recycle.Bin` / `System Volume Information` **永不遍历**（安全前提）。所以空间地图在 C 盘上统计的是"工具能碰的那部分" |
| 空间地图的深度 | `depth` 之外的文件**不参与统计**（不是"看不到"，是"没算"）。默认 3 层；折叠节点显示「未展开」并可按进去重扫 |
| NTFS MFT | **没有**用 MFT/USN 直读做秒级全盘枚举。全盘扫描仍走目录遍历 |
| 重复文件 | 只比**字节完全一样**（三层：大小 → 头部 → 全量 SHA256） |
| 相似图片 | 用 dHash，能找"缩过/压过/另存过"的同一张图。但它**对旋转不免疫**（转 90°/180° 会漏），且**纯色图会被跳过**（无明暗起伏，指纹没有信息量） |

## 三、写入类操作

| 项目 | 现状 |
|---|---|
| 回滚 | 每个任务能整体回滚自己的动作，但**没有跨任务的"撤销上一步"** |
| 隔离区 | 删除一律先进隔离区。**空隔离区才会真正释放磁盘空间** —— 所以「累计腾出」这个数字指的是"已移走"，不等于"已释放" |
| 定时任务 | `scheduler.py` 有调度骨架（kind + params + interval），但**还没有"跑完自动执行安全项"这类编排** |
| 权限档 | 三档（只读/标准/完全）。**只读档下所有写入口都被拒** —— 包括回滚和还原隔离区 |

## 四、跨页与交互

| 项目 | 现状 |
|---|---|
| 接力方向 | 目前只有 **空间地图 → 查重 / 清理 / 迁移 / 项目雷达** 这一向。反方向（从查重结果、垃圾清单跳到别处）**还没做** |
| 接力行为 | 只把目录**填好**，不自动开跑（保持"先出清单等确认"） |
| 进度百分比 | 会**跨阶段倒退**：统计阶段 25% → 进入候选比对 6%（分母从"条目数"换成"候选数"）。要修得改 `JobContext.progress` 的语义 |

## 五、模型与联网

| 项目 | 现状 |
|---|---|
| 联网点 | 全项目**只有两处**：① Agent 助手页；② 每个待清理项旁边的「?」解释（**必须手动点**，不点就永远不联网） |
| 除这两处 | 全部零 token、纯本地、可断网 |
| 模型 | 只对接 **DeepSeek**（OpenAI 兼容接口）。没有多 provider 抽象 |
| 断网 | Agent 页会退回本地规则（能认出的照常处理）；「?」解释会如实说"连不上" |

## 六、已知遗留（都是"知道但还没动"）

1. **空会话不落库** —— 新建的会话在发出第一条消息前不会出现在后端列表里，切走再回来就找不到（既有设计，见 `docs/UI_REVAMP.md` v26）。
2. **删除配额** —— 沙箱/宿主环境有批量删除守卫，清理与构建**不能写进同一条命令**，否则被拦会把构建一起带崩（见 `docs/GOTCHAS.md` 十·4）。
3. **`smoke_test` 的环境前提** —— 只能对着"工作目录 = 仓库"的后端跑；对打包版跑时「保护目录护栏」3 项必然失败（测试样本建在仓库根）。
4. **Agent 任务的进度条** —— 步内无法量化，`fraction` 写死 0.5；表现是百分比不动（靠流动高光 + 实时秒数 + 实时条目数补）。
5. **空间地图的总数口径** —— 因为不遍历系统只读区，C 盘上的总数**不是**"C 盘占用"。界面上有口径说明，但数字本身容易被误读。
6. **接力仍是"就近"的**：现在双向都有入口，但只覆盖 空间地图 / 查重 / 垃圾 / 迁移 / 项目雷达 / 扫描这几页，
   整理预览与备份还没接。
7. **清理规则可被用户覆盖，但不可被"删除"** —— 想停用某条内置规则要在 `junk_rules.json` 里写
   `{"id": "xxx", "disabled": true}`，而不是"从内置表里拿掉"（不给自己留"悄悄少一条安全规则"的口子）。

## 七、明确的"不做"

- **不动注册表、不删浏览器数据、不改启动项** —— 这一类"系统优化/隐私清理"风险级别与本工具的定位不匹配（对标项目 MangoDisk 做了，我们不做）。
- **不扫"损坏文件 / 错误扩展名"** —— 误报率高，价值低。
- **不做插件 SDK** —— 自用工具不需要。
