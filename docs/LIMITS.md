# 当前限制与已知遗留（2026-10-21）

本文记录当前版本仍做不到什么，避免把产品边界误判成故障。状态以代码、测试和发行配置为准。

## 平台与分发

| 项目 | 当前状态 |
| --- | --- |
| 操作系统 | 仅支持 Windows。启动器、DPAPI 密钥保护、NTFS junction 防护和安装器均按 Windows 实现；没有 macOS/Linux 验证。 |
| 界面语言 | UI 为简体中文；README 提供中文、英语、日语、韩语、德语、俄语和西班牙语版本，应用本身没有多语言切换。 |
| Python | 源码要求 Python 3.11+，CI 对 3.11 和 3.12 分别运行后端检查。发行版包含运行时，用户无需安装 Python。 |
| 发行形式 | Windows 便携 ZIP；`packaging/Atlas.iss` 可选生成按用户安装的 Inno Setup 安装程序，无需管理员权限。 |
| 更新 | 没有自动更新或自动检查更新。用户从 GitHub Releases 手动下载。 |
| 签名 | 当前未配置 Windows Authenticode 代码签名，Windows 可能显示来自未知发布者的提示。 |
| 校验 | release 构建脚本生成 ZIP 的 SHA256 sidecar；验证时要确保 sidecar 与下载的 ZIP 文件名相同。 |

## 扫描、检索与查重

| 项目 | 当前状态 |
| --- | --- |
| 增量扫描 | 全盘/目录扫描任务每次重新遍历。全文检索索引有独立的增量更新逻辑。 |
| 系统目录 | Windows、Program Files、ProgramData、回收站等系统只读位置不会被遍历；空间地图只统计允许扫描的部分，不等同于磁盘实际已用空间。 |
| 扫描上限 | 单次扫描受 `FILEPILOT_SCAN_LIMIT` 限制，默认最多处理 400,000 个条目。 |
| 空间地图 | 按所选深度统计；超出深度的内容不计入当前结果，需要继续钻取才能查看。 |
| NTFS 快速枚举 | 未使用 MFT/USN Journal 直接枚举；仍通过目录遍历读取文件系统。 |
| 完全重复 | 按大小、文件头和 SHA256 判断字节完全相同，不判断语义或近似内容。 |
| 相似图片 | 感知哈希适用于经过缩放、压缩或另存的相同图片；纯色图片会跳过。旋转容忍默认关闭，开启后会增加哈希计算量。 |
| 全文检索 | 仅索引用户指定的目录；纯文本文件正文有类型白名单，默认单文件上限 2 MiB（`FILEPILOT_SEARCH_MAX_BYTES` 可调）。PDF、Office 文档及图片 OCR 不抽正文，但文件名仍可检索。搜索索引依赖 SQLite FTS5。 |
| 中文检索 | 使用逐字预切与相邻短语匹配，不提供分词词典、同义词或词干搜索。多查询词按 AND 组合。 |
| 文件内容联网 | 本地搜索本身不联网；当用户让 Agent 搜索内容时，命中 snippet 可能作为上下文发送给所配置的模型服务，详见 [PRIVACY.md](../PRIVACY.md)。 |

## 写操作、撤销和权限

| 项目 | 当前状态 |
| --- | --- |
| 写入边界 | 用户文件写操作统一经过 `backend/execution.py`；权限档、受保护路径、junction/symlink 和目录边界由本地代码判定。模型只能提出计划，不能直接执行文件写入。 |
| 默认清理 | 手动清理默认将文件移入隔离区，可从回收站恢复。恢复可能因原路径被占用、文件系统错误等失败，界面会报告结果。 |
| 不可逆清理 | Agent 清理在用户确认后会清理本批隔离文件；清空隔离区也不可撤销。这些操作会明确标记并要求确认。 |
| 迁移 | 先复制并校验，再处理来源；可撤销性取决于任务记录和文件当前状态。跨盘断电、磁盘故障等不由应用提供事务级保障。 |
| Journal / Undo | 操作流水支持按记录撤销仍标记为可撤销的任务。并非每类操作都可撤销；永久删除、外部修改或文件冲突可能使撤销不可用或失败。 |
| 权限档 | `readonly`、`standard`、`full` 三档。只读档拒绝写任务；`full` 也不能绕过项目自身目录、运行数据目录和隔离区的自保护。 |
| 断电事务 | 没有 WAL 级文件操作事务或断电后自动恢复；Journal 记录用于追踪与受支持操作的撤销，不是文件系统事务日志。 |

## Agent、Provider、MCP 与定时任务

| 项目 | 当前状态 |
| --- | --- |
| Provider | 支持 DeepSeek、OpenAI 和自定义 OpenAI 兼容 endpoint。已保存的当前 Provider Key 优先；环境变量只读取对应服务商的变量，不跨服务商回退。 |
| 联网点 | 需要模型的 Agent 请求，以及用户主动点击的 AI 清理解释会连接模型服务。常见文件意图可由本地规则处理。 |
| 模型数据 | 模型请求可能包含消息、必要路径、工具 schema、结果摘要；用户要求全文检索时还可能包含命中正文片段。Atlas 不把文件二进制作为请求内容发送。 |
| Agent 工具 | 共 48 个：26 个执行动作、16 个只读查询、6 个导航辅助。定义集中在 `backend/services/tool_specs.py`；`tests/test_tool_registry.py` 会防止注册项与实际工具漂移。 |
| 写操作确认 | 写操作需要本地风险判断和用户确认。不可逆的隔离区清空/Agent 清理有单独的风险标记和确认流程。 |
| CLI | `python -m backend.cli` 提供只读扫描与分析命令，没有删除或移动命令。 |
| MCP | `Atlas.exe --mcp --allow <目录>` 提供只读工具和路径白名单；白名单为空时拒绝访问。安全例外见 [MCP_SECURITY.md](MCP_SECURITY.md)。 |
| 定时任务 | 数据模型和 API 有定时任务配置，但应用启动时没有启用调度执行器，也没有面向用户的完整管理 UI；不能依赖它执行后台计划。 |

## 自动化检查

CI 使用 Windows runner，后端测试 Python 3.11/3.12，Ruff 覆盖 `backend/`、`tests/`、`packaging/` 和 `main.py`，另有安全子集与前端生产构建。GitHub Actions 状态以仓库最新 run 为准；本地通过不代表远端 run 已成功。

端到端 `tests/smoke_test.py` 需要单独启动从仓库根目录运行的测试后端。它不是便携版 smoke：打包版的 UI/health 验证由 `packaging/smoke_release.ps1` 执行，两者用途不同。

## 明确不做

- 自动更新系统、自动崩溃上报或使用统计。
- Windows 注册表、启动项、浏览器数据清理或“系统优化”。
- MFT/USN Journal 极速扫描、macOS/Linux 发行版。
- Windows 代码签名证书与企业级集中策略。
- WAL 级断电文件事务、跨任务全局“一步撤销”。
