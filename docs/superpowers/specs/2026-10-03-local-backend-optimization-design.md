# FilePilot Lite 本地桌面后端优化设计

**日期：2026-10-03**

## 目标

将 FilePilot Lite 优化为稳定的本地下载即用工具：后端仅监听本机，任务、日志和回收站记录可靠持久化，文件操作可验证、可取消、可回滚，并兼容不同 Windows 用户环境。

## 非目标

不实现账号、注册、云端同步、多租户、远程访问、云数据库或在线任务队列。

## 架构

Vue 前端通过 localhost 调用 FastAPI；FastAPI 通过 JobManager 调度本地后台任务；文件系统访问统一经过 fsutil 安全层；SQLite 保存任务、日志和隔离区账本；JSON 继续保存设置和配方。

## 数据与迁移

新增 `.filepilot/filepilot.db`，启用 SQLite WAL。首次启动时从现有 `jobs.json`、`logs.json`、`trash.json` 导入，不删除旧文件；迁移过程幂等。settings.json 与 recipes.json 保持现状。

## 任务系统

使用固定线程池，默认最多 2 个并发任务。任务状态保留现有兼容状态并增加 partial。所有任务变化以事件序号发布；终态事件不可丢失。进程重启时活动任务标记为 failed。

## 安全

仅绑定 127.0.0.1；CORS 限定本地前端；所有输入路径进行 resolve、边界和保护目录检查；迁移 items 必须属于源目录且目标必须属于目标目录；禁止源目录为目标目录的祖先/子目录关系；默认不跟随符号链接。

## 性能与可靠性

任务进度持久化节流；扫描和大计划避免无限制内存增长；备份使用 partial 文件并在完成后原子改名；API 参数限制范围；统一错误状态码和结构化错误响应。

## 验收标准

- 全部新增测试通过。
- `python -m compileall backend tests` 通过。
- FastAPI 应用可导入，`/api/health` 返回 200。
- 本地服务不监听非回环地址。
- 旧 JSON 数据可迁移到 SQLite，重复运行迁移不重复导入。
- 路径保护、迁移校验、取消、回滚和备份中断有自动化测试。
