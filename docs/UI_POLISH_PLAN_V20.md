# 全站 UI 优化方案（v20 提案）

> 性质：**设计方案，待确认后转 Codex 提示词**。
> 依据：13 个页面在 1385×860 下的逐页截图审查（浅色态）。
> 前提：延续全部已定稿决策（无页头、无桌面顶栏、侧栏形态、Agent v19 形态、聚焦无反馈、灰底白卡），**只做补齐与收敛，不推翻**。

---

## 一、全站通病（按影响排序）

### 1. 空态是一句完整的话，而且 6+ 页同一句

「还没有任务。填好上面的路径后点击开始。」出现在空间地图 / 扫描 / 垃圾 / 查重 / 迁移 / 备份 / 整理预览 / 项目雷达。
违反 v8「删句子、留名词」；且它是 `JobProgress` 组件的空态混进了业务页。

**改法**：
- `JobProgress` 的空态改为**可配置名词标题**（默认「暂无任务」），业务页传入各自的短标题；
- 业务结果区一律用 `EmptyState`（图标 + 名词标题 + 至多一个动作按钮）；
- 各页标题建议：空间地图「先生成一次空间地图」、扫描「先运行一次扫描」、垃圾「先做一次垃圾检查」、
  查重「先跑一次查重」、迁移「先生成迁移计划」、备份「先做一次备份」、整理预览「先生成一次预览」、项目雷达「先扫描一次项目」。

### 2. 「执行进度 / 任务进度」卡在没有任务时是一整张空卡

Scan / Migrate / Junk / Backup / Space 的第二张卡里只有一条虚线，纯占地方。

**改法**：无任务时**整卡隐藏**（`v-if="job.job.value"`）；有任务才出现。页面少一个视觉块，空态不再有「两张空卡」。

### 3. 时间戳全站仍是长格式带时区

任务中心列表与日志表格都是 `2026-10-02 23:44:49+08:00`——时区是噪音，秒在扫视时无用，列宽还被撑爆。

**改法**：把首页里的 `shortTime()` **提升到 `utils/formatters.js`** 为 `formatShortTime()`（输出 `10-02 23:44`），
任务中心 / 日志 / 首页统一使用；完整时间放 `title` tooltip。首页本地的 `shortTime()` 随之删除。

### 4. 表单型页面下半屏全空

空间地图 / 扫描 / 垃圾 / 查重 / 迁移 / 备份空态时内容只到 ~300px，下面 500px 空白；且卡片被拉满 1080px 宽，表单行松散。

**改法**：**表单型页面内容区 `max-width: 920px; margin: 0 auto`**（空间地图 / 扫描 / 垃圾 / 查重 / 迁移 / 备份 / 整理预览 / 项目雷达）；
表格型页面（任务中心 / 操作日志 / 回收站）保持全宽。卡片变窄后表单行更紧凑，「大气」来自留白而不是拉伸。

### 5. 全宽 el-alert 色带太多

扫描 / 迁移 / 备份 / 整理预览 / 项目雷达每页一条灰或黄的整宽色带（安全说明）。信息要保留（v8 已定），但视觉重量过大。

**改法**：**降为卡片内的一行注脚**——`ⓘ 安全说明文字`，12px `--ink-3`，不套色带、不占整行；
只有「危险动作确认」类（迁移的黄色提示）保留 `--warning-soft` 底，但也收成一行、不全宽。

### 6. 任务中心：列表扫不动、详情太空

- 列表项**没有状态**——成功 / 失败 / 取消要点进详情才知道；
- 时间戳长格式（见 #3）；
- 详情卡内容只有状态 + 阶段条 + 一行 meta，下方大片空白。

**改法**：
- 列表项标题行尾加**状态点**（沿用「6px 圆点 + 文字」规范）；
- 详情区分成三段：**阶段条 / 参数（键值对）/ 结果摘要或错误**，用 `--hairline` 分隔，把卡填实；
- 两栏比例 5:7 → **4:8**（详情是主角）。

### 7. 日志表：路径与备注两列重复

「路径」列是路径，「备注」列常常是「动作 + 同一路径」。

**改法**：备注列只保留动作说明（不再拼路径）；两列都 ellipsis + tooltip。

### 8. 首页左右两栏底边不齐

`align-items: start` 之后，「接口调用」8 行把右卡撑到 ~530px，左卡 370px 就结束了，左下有一块空白。

**改法**：接口调用 **TOP 8 → TOP 5**（首页本就该是「概览」，前 5 足够；「查看全部 →」还在），两卡高度接近。

## 二、分页要点

| 页面 | 提案 |
|---|---|
| 首页 | 接口调用 TOP 5；其余不动 |
| Agent | **不动**（v19 刚定稿） |
| 空间地图 / 扫描 / 垃圾 / 查重 / 迁移 / 备份 | max-width 920px；空态换 EmptyState；无任务时隐藏进度卡；alert 降为注脚 |
| 整理预览 / 项目雷达 | 同上；结果区 EmptyState 的**说明句删掉**，只留名词标题 |
| 任务中心 | 列表加状态点、时间短格式；详情 4:8 并补 参数/结果/错误 三段 |
| 操作日志 | 备注列去重、时间短格式 |
| 回收站 | max-width 920px（内容少时不拉满） |

---

## 三、明确不做（防止翻烙饼）

1. 不恢复页头 / 顶栏 / 侧栏分组标题 / 状态行；
2. 不给输入框加任何聚焦特效（v19-h）；
3. 不引图表库、不加卡片毛玻璃、不动灰底白卡；
4. 不做深色模式专属调整之外的新配色（深浅两态只做核对）；
5. Agent 页除小修外不动结构；
6. 不新增页面/选项卡（含「设置」页——配置仍留在 Agent 页内）。

---

## 四、验收标准（转 Codex 时作为硬性条款）

1. `grep` 无字面量颜色、无字面量时长（既有豁免除外）；
2. `python tests/smoke_test.py`（FILEPILOT_API 指向 8001 独立实例）**73/73 全绿**；
3. `vite build` 通过（dist 清空被环境拦截时用 `--outDir` 换目录）；
4. 13 页 × 深浅两态逐页截图自查，重点核对：空态无整句文案、无空进度卡、时间戳为短格式；
5. 完成后在 `docs/UI_REVAMP.md` 追加 v20 章节（改动清单 + 新踩的坑）；
6. 只 commit，不 push。
