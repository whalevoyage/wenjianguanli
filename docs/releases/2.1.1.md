# Atlas 2.1.1

本次版本完成发布前工程整改，保留现有文件管理和 Agent 功能。

- Custom OpenAI-compatible 服务的远程地址必须使用 HTTPS；localhost 和 loopback 本地 HTTP 服务仍可使用。
- 修复 Python 包发现和 launcher 命名冲突，安装后可使用 `atlas --version`、`atlas-cli --help` 和 `atlas-mcp --help`。
- 补齐 Python 传递依赖锁，修复依赖审计发现的问题，并更新 npm 锁中的兼容修复版本。
- 增加依赖审计、Gitleaks Secret Scan、安装入口检查及 Windows Release Check。
- 明确普通手动清理的恢复条件，以及 Agent 永久清理和隔离区清空不可恢复的边界。
- 修复 Agent 长文本正则回溯风险；CSV 清单导出只接受已注册分组模式，避免不可信分组名进入输出路径。CodeQL 复核依据见 [CODEQL_TRIAGE.md](../CODEQL_TRIAGE.md)。

Windows 便携包同时提供同名 `.sha256` 校验文件。下载后可用 `Get-FileHash` 核验。

本版本尚未提供 Windows Authenticode 签名。自动更新与 MFT/USN 扫描留待后续版本。
