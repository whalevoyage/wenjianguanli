# 给 Codex 的实施提示词（Atlas 界面精修 v19）

> 使用方法：把下面「提示词正文」整段复制给 Codex。它面向的仓库是 `D:\FilePilotLite`（显示名 Atlas）。

---

## 提示词正文

你在这个仓库里做一次**纯前端视觉精修 + 信息增量**，不改任何后端业务逻辑。先完整读这两份文件再动手：

1. `docs/UI_REVAMP.md` —— 已定稿的视觉规范与全部历史结论（v11~v18），其中的「禁用清单」和「不做清单」是铁律。
2. `docs/UI_REFINEMENT_PROPOSAL.md` —— 本次要实施的设计方案，逐条照做。

### 项目硬约束（违反任何一条都算失败）

- **唯一事实源是 `frontend/src/styles/global.css`**。视图与组件里**不允许出现字面量颜色**，只写 `var(--*)`。完工后自检：`grep -rnE '#[0-9a-fA-F]{3,6}|rgba?\(' frontend/src/views/ frontend/src/components/` 应为空（既有豁免除外）。
- **禁止 `transition: all`**，逐属性枚举；**禁止字面量时长**，一律用 `--duration-*` / `--ease-*` 令牌。自检：`grep -rnoE 'transition:[^;]*[0-9]+(\.[0-9]+)?(s|ms)' frontend/src/` 应为空。
- 不新增色相、不引图表库、不装新依赖；装饰只用主色一个色相，语义色只在表达状态时出现。
- 卡片一律 `--surface` + `--hairline` + `--sh-1`，**不加 `backdrop-filter`**。
- 表格页**保留可见滚动条**（滚动条隐藏仅限侧栏导航）。
- 文案准则：删句子留名词；不写第二人称、劝说、口语比喻；空态 = 图标 + 名词标题 + 至多一个按钮。
- 新增数据全部来自本地已有接口 / `.filepilot/` 状态，**零 token、零新增网络依赖**。若某张表需要的数据现有接口没有，就在 `backend/` 按既有分层补一个只读聚合接口（`main.py` 只校验，`services/` 做业务），**不许在路由里写业务**。
- 规则类数据（如文件类型分类）只能引用 `backend/config.py`。
- 只 commit，不 push。

### 实施范围（按优先级，P0 → P2 全做）

**P0-1 数字排版**（`global.css` + 各视图）
- 所有数值加 `font-variant-numeric: tabular-nums`（StatCard 数值、表格数字、磁盘百分比、进度数字）。
- 容量/计数单位降一级：12px、`--ink-3`、不加粗，与数字本体分离成独立 `<span>`。
- 表格数字列右对齐（表头同步右对齐），文本列左对齐，状态列居中。
- 表头样式统一：12px / 600 / `--ink-2` / 字距 0.02em。

**P0-2 首页两张新表 + 最近任务表**（`Home.vue`）
- 磁盘健康明细表：盘符 · 文件系统 · 已用 · 可用 · 总计 · 占用率（内嵌细进度条+数值）· 状态点（复用磁盘条既有三级阈值与色级，不新造规则）。点击行跳「空间地图」。
- 接口调用统计表：扩展现有 TOP5 为 TOP8，列 = 接口 · 次数 · 占比细条 · 最近调用时间，底部「查看全部 →」跳操作日志。
- 最近任务表（通宽，替代现有简易列表）：任务类型 · 目标路径（截断+tooltip）· 结果摘要（名词短语）· 耗时 · 完成时间 · 状态；点击行跳任务中心并选中；失败行尾加「回滚」文字按钮。
- 布局：指标带（3 张 StatCard 不变）→ 双栏 7:5（左磁盘表 / 右接口表，同高顶对齐）→ 最近任务通宽 → 快捷入口 4 张 ActionTile 收尾。

**P1-1 筛选行归位**（`Scan.vue` / `Logs.vue` / `Jobs.vue`）
- 筛选控件统一移到卡片外独立一行，左对齐，顺序：主筛选 → 次筛选 → 弹性空隙 → 右侧刷新/导出；控件统一 default 尺寸。

**P1-2 状态标签统一**
- 全站状态收敛为「6px 圆点 + 13px `--ink-2` 文字」，无底色无描边；仅「等待确认」用 `--warning-soft` 底 + `--warning-ink` 药丸。替换 `Jobs.vue`、`Home.vue` 等处的 `el-tag` 状态写法。

**P1-3 大文件 TOP 10 表**（`Scan.vue` 结果区）
- 列：排名 · 文件名 · 所在目录（`--ink-3`）· 大小 · 类型 · 修改时间；大小/时间列可排序；点击行调系统「打开所在位置」（如现有接口没有就补一个只执行 explorer 打开的本地接口）；不提供删除入口。空态 = 「先运行一次扫描」+「去扫描」按钮。

**P1-4 ActionTile 图标色块**
- 实心主色块 → `--primary-soft` 底 + 主色图标（与侧栏选中态同构）。

**P2-1 文件类型分布表**（扫描分析页）
- TOP10 + 「其他」合并行：类型 · 文件数 · 总大小 · 占比细条；点击类型跳空间地图过滤。分类规则必须来自 `backend/config.py`。

**P2-2 回收站构成表**（`Trash.vue` 顶部）
- 按来源操作聚合：来源 · 项目数 · 占用空间 · 最早进入时间；点击行过滤下方明细；行尾「还原该类 / 清空该类」文字按钮（走既有确认流，不绕过安全分级）。

**P2-3 查重分组汇总表**（`Duplicates.vue` 结果区）
- 组号 · 文件数 · 单文件大小 · 冗余占用 · 哈希前缀 8 位 · 分布目录数；默认按冗余占用降序；行内展开组内明细。

**P2-4 布局基线**
- `global.css` 收敛：页面左右内边距 32px（<1280px 降为 24px）、页面上边距 28px、`section-stack` gap 24px、卡片内边距统一 24px（表格卡 16px/0）。

### 明确不做（做了要回退）

不恢复桌面顶栏 / 侧栏状态行 / 导航分组标题；不加背景纹理、光晕、彩色装饰线；不动 `--bg #F4F5F7` 与 `--surface #FFFFFF`；不压侧栏导航 52px 行高；不加欢迎语/日期横幅；不给首页加图表。

### 验收（全绿才算完成）

1. 两条 grep 自检为空（字面量颜色、字面量时长）。
2. `cd frontend && npm run build` 通过（注意：`vite build` 若清空 `dist/` 被环境拦截，用 `--outDir` 换新目录）。
3. 起后端 `start_backend.bat` 后跑 `python tests/smoke_test.py`，44 项断言全绿。
4. 逐页截图自查：浅色 + 深色两态，确认无新色相、无对比度回退、表格数字右对齐生效。
5. 完成后在 `docs/UI_REVAMP.md` 追加 v19 章节：改动清单 + 新踩的坑（若有）。
