**Локальное и контролируемое управление файлами и очистка диска в Windows: сначала предварительный просмотр, явное подтверждение, журналирование действий, откат там, где он поддерживается, и ИИ-агент.**

Анализ, поиск дубликатов, очистка от мусора, перенос между дисками и карта пространства помогают сначала оценить изменения.

Операции записи сначала показывают список затрагиваемых файлов и ждут подтверждения. При ручной очистке файлы по умолчанию перемещаются в карантин; восстановление возможно, если исходный путь и состояние файловой системы это позволяют. Окончательная очистка Агентом и очистка карантина необратимы, они отмечаются отдельно и требуют дополнительного подтверждения.
ИИ только понимает запрос и составляет план — файлы изменяет исключительно локальный код.
Кроме запросов к модели Agent и запрошенных пользователем ИИ-объяснений, сканирование, поиск дубликатов, очистка, перенос и резервное копирование выполняются локально. Учётная запись не нужна.

> Он не решает за вас. Он показывает, каких файлов коснётся действие.

## Быстрый старт

1. Скачайте [Atlas-2.1.1-win64-portable.zip](https://github.com/whalevoyage/wenjianguanli/releases/latest) и распакуйте в любое место (например, `D:\Atlas`)
2. Дважды щёлкните `Atlas\Atlas.exe`
3. Браузер откроется автоматически. Окно консоли не появляется.

Python, Node и другие среды выполнения не нужны. Программа слушает только `127.0.0.1`, данные хранятся в `%LOCALAPPDATA%\Atlas`.
Удаление — это просто удаление этой папки.

**Повторный двойной щелчок не запускает второй экземпляр** — он открывает уже работающий.
**Если порт 8000 занят, выбирается свободный**, фактический адрес пишется в лог.

## Возможности

| Раздел | Назначение |
| --- | --- |
| Главная | Объём диска, освобождаемое место, статистика и последние задачи |
| Агент Atlas | Управление на естественном языке; сначала файловые задачи, но отвечает и на общие вопросы |
| Карта пространства | Древовидная карта занятости папок с пошаговым углублением |
| Предпросмотр организации | Предпросмотр по типу, времени, размеру или проекту — только чтение |
| Радар проектов | Находит папки проектов: тип, размер, число файлов, давно неиспользуемые |
| Анализ сканированием | Количество, объём, распределение по типам, крупные и давно нетронутые файлы; снимки для сравнения «до/после» |
| Дубликаты | Побайтовый поиск дубликатов; включая «похожие изображения» (уменьшенные, пережатые, пересохранённые; с допуском на поворот) |
| Мусор | Временные файлы, логи, кэши, пустые папки и файлы нулевого размера, три уровня риска |
| Полнотекстовый поиск | Локальный индекс FTS5 по папке, поиск по именам и содержимому |
| Перенос между дисками | Копирование с поэлементной проверкой; источник затрагивается только после неё; возможен откат |
| Резервная копия проекта | ZIP-снимки без папок зависимостей и сборки; проверка восстановления |
| Центр задач | Прогресс, ошибки, отмена и статус отката |
| Корзина | При ручной очистке файлы сначала идут в карантин; восстановление возможно, если это позволяют исходный путь и файловая система |
| Журнал операций | Просмотр записей аудита и экспорт |

## Безопасность

- При ручной очистке сначала показывается список, а после подтверждения файлы по умолчанию перемещаются в карантин. Восстановление возможно, если это позволяют исходный путь и файловая система. Окончательная очистка Агентом и очистка карантина необратимы и требуют отдельного подтверждения.
- Перенос сначала копирует и проверяет; источник затрагивается только после успешной проверки.
- Долгие операции выполняются как фоновые задачи с прогрессом, отменой и откатом.
- Папка самого проекта, папка состояния и карантин защищены.
- Системные папки по умолчанию не сканируются. В стандартном режиме запись туда запрещена; режим полного доступа позволяет явно ослабить эту защиту. Собственные данные Atlas и карантин остаются защищёнными.
- По умолчанию исключаются `node_modules`, `.git`, `__pycache__`, `.venv`, `dist`, `build` и подобные.
- Перед переносом и копией проверяется свободное место на целевом диске.
- Слушает только `127.0.0.1`, в локальную сеть не выставляется.
